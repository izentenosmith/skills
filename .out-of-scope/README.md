# Out of scope

Ideas this repo tried and took out, or turned down, kept so a later session doesn't propose them
again. The rules for what gets in are in [SCOPE.md](../SCOPE.md).

One file per idea, named for the idea, with:

- **The idea**: what it was, in a sentence or two.
- **Why it's out**: the failure or cost that settled it, not a preference.
- **Evidence**: the commit that added or removed it (short sha), and any note in `.memory/`.
- **What would reopen it**: the observed failure that would make it worth another look.

A rejection is a decision, not a law. To bring an idea back, show the failure that reopens it.
