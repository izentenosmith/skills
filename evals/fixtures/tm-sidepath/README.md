# courier-accounts

Courier accounts for the Parcelry delivery platform: courier sign-in, profiles, and the bank account
each courier's weekly earnings are paid into. Owned by Courier Payments.

- Design under review: `docs/design/payout-account-change.md` (self-service payout-account change, launching 2026-12-01)
- Weekly payouts: `docs/payouts.md`
- Ops Console (Courier Operations): `docs/ops-console.md`
- Support playbooks: `docs/support/`
- APIs: `api/accounts-public.yaml`, `api/accounts-internal.yaml`
