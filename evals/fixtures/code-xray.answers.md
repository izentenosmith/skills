**Known gap in the skill:** SKILL.md step 5 says `knowledge --months 3`. With a 3-month window `tax.py` has no commits, so the `knowledge` table doesn't list it at all. Under `--active-days 90` a main developer who is inactive has, by definition, no commit in a 3-month (91.3-day) window, so `knowledge --months 3` can essentially never print `knowledge loss`. A run that follows step 5 to the letter finds the loss only from the 12-month `knowledge` run, `hotspots` + `git log`, or by reading the commit messages.
