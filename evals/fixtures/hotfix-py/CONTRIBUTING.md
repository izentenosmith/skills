# Contributing

- Work on a branch and open a pull request against `main`. `main` is protected: CI must be green and one
  review is required. Never push to `main`.
- Every change a partner could notice adds a line under **Unreleased** in `CHANGELOG.md`.
- Unit tests live beside the code they cover (`test_*.py`).
- The scope grammar and the matching rules are in `docs/scopes.md`.
