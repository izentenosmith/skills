# Glossary

The ledger and the payment providers use these names. Code uses them as written.

| Term | Meaning |
|---|---|
| `amt_minor` | An amount in minor units (cents for EUR and USD), as an `int` |
| `ccy` | An ISO 4217 currency code, upper case (`EUR`) |
| `psp_ref` | The payment provider's reference for a charge, refund or payout |
| `ledger_ts` | The time a posting takes effect in the ledger, UTC |
| `merchant_id` | Harbor's id for a merchant account |
| settlement | The provider's daily statement of what it paid out to a merchant |
| Ledgerly | The settlement provider for EU merchants |
