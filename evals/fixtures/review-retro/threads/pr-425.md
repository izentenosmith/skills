**@tferreira** (Tomás Ferreira) · 2026-07-21 15:02 — Ledgerly rate-limits `/v2/settlements` at 3 calls per
rolling 60 seconds per merchant. A 4th call inside the window gets a 429 and locks that merchant out for
10 minutes, which means the day's settlement is late. So at most 3 tries, 21 s apart, keeps us inside one
window. It's in their support docs but not in the API reference.
