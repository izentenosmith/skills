# Skill registry

Generated by `.github/scripts/registry.py` from each `SKILL.md`'s frontmatter, `skills/shared.json`, `evals/scores.json` and `CHANGELOG.md`. Do not edit it by hand: run `python3 .github/scripts/registry.py`. CI fails when it is stale.

Skills are versioned with the repo, not one by one: every skill is at the repo's release version, the top released heading of `CHANGELOG.md` (`unreleased` when there is none). Purpose is the description's first sentence. Owner comes from `CODEOWNERS`, else the repo owner. Dependencies list only what is certain: files copied in from another skill or from `harness/` (see `skills/shared.json`), scripts the skill carries, and `harness/` when a scored run staged the skill beside it. Last eval is the UTC day the latest scored with-skill run ended; each eval shows its with-skill delta and capability means (see [evals/benchmark.md](../evals/benchmark.md) for baselines and noise).
